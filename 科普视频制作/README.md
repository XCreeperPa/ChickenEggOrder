# 科普视频制作

本目录记录 ChickenEggOrder 科普视频的制作思路、叙事结构、资产策略和授权信息。

视频计划发布于 B 站，以 Lean 4 为例介绍形式化证明。项目使用“鸡和蛋谁先”
这个家喻户晓的问题，引导观众理解：一个直觉问题如何被拆成形式系统，
如何写成可由证明助手检查的 Lean 代码，以及这种思维方式如何启发我们理解
未来智能系统中的可验证约束。

## 项目定位

本项目是一个以 Lean 4 为例的形式化证明科普项目。

它不是为了直接回答现实生物学中的鸡蛋起源问题，而是为了展示：

- 自然语言问题如何变成形式定义。
- 直觉中的因果关系如何变成公理和关系。
- 一个命题如何被写成 Lean 定理。
- 证明助手如何验证证明链条。
- Agent 可以辅助写证明，但最终正确性仍应交给形式系统检查。

AGI 相关内容不进入 Lean 代码本身。代码保持为纯粹、可验证的形式化证明内核；
AGI 与未来约束模式的讨论放在视频叙事中，通过“Agent 辅助证明，Lean 负责验证”
的演示来呈现。

## 语言规范

本视频及相关制作文档以简体中文为第一语言。

面向观众的文案、旁白、字幕、分镜说明、制作记录和 B 站简介应优先使用简体中文。
必要时可以保留英文术语，尤其是 Lean、Lake、Manim、proof assistant、
formal verification、agent、AGI 等既有技术词汇。

授权文本、外部素材署名和第三方要求应保留英文原文，并同时提供中文翻译或说明。

## 目录说明

- `叙事大纲.md`：视频主线、段落结构和核心表达。
- `资产清单.md`：视觉、字体、音频、代码演示等资产计划。
- `音乐授权.md`：Vincent Rubinetti 音乐授权要求、署名文本和中文翻译。
- `Manim制作说明.md`：Manim 动画风格、对象设计和镜头建议。

## 核心表达

这个视频最重要的表达不是“AI 帮我们解决了鸡蛋问题”，而是：

> 一个古老的哲学问题，经过形式化建模，变成了机器可检查的证明；
> 而未来更强的智能体，也需要在这样的可验证结构中被理解、协作和约束。
